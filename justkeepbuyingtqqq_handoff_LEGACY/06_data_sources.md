# 데이터 소스 상세 설명 (첨부 파일 4종)

## 1. `ndx 1971_now.csv`
- **컬럼**: `Date, Close`
- **기간**: 1971-02-05 ~ 2026-09-25
- **내용**: 나스닥종합지수(초기) → NDX(나스닥100, 이후)로 소스가 전환된 일별 종가 시리즈.
- **알려진 결함**: 1985-10-01 부근에서 소스 전환으로 인한 가짜 -60% 급락 존재. 재사용 시 `01_methodology.md`
  의 비율보정 코드를 반드시 적용할 것.
- **용도**: NDX 1x(QQQ 근사), 2x(QLD 근사), 3x(TQQQ 근사) 전부 이 파일 하나에서 레버리지 합성 공식으로 생성.
  이것이 이 프로젝트의 **가장 핵심적인 원천 데이터**임.

## 2. `sp500_1927_now.csv`
- **컬럼**: `Date, Close`
- **기간**: 1927-12-30 ~ 2026-09-03
- **내용**: S&P500 일별 종가 시리즈.
- **용도**: SPX500/VOO 1x 백테스트 원시 가격 데이터. 이전 핸드오프 패키지에는 포함되지 않았으나 이번 패키지에 추가됨.
  `sp500_1927_now.csv`로 SPX500 백테스트를 직접 재현/확장할 수 있음.
- **참고**: NDX 데이터(~2026-09-25)보다 약 3주 짧게 끝남(2026-09-03). 최신 데이터 연장이 필요하면 별도 수집 필요.

## 3. `mcv_ndx_2x_monthly_10b.json`
- **컬럼**: `id, start_date, end_date, days_to_target, status, final_value, accumulated_investment,
  accumulated_shares, years_to_target, created_at, updated_at`
- **행 수**: 627개 코호트
- **내용**: NDX 2x, A전략(매일 20만원, 누적 2.5억 도달 시 중단), 목표 10억 — 에 대한 **사전계산된 결과**.
- **용도**: 새로 작성하는 백테스트 코드가 `ndx 1971_now.csv`로부터 이 결과를 **정확히 재현하는지 검증하는
  골든 테스트셋**으로 사용. (이전 세션에서 이 파일로 로직을 역으로 검증해서 "일 20만원, 2.5억 cap" 방식임을
  확정함.)

## 4. `mcv_spx500_1x_monthly_10b.csv`
- **내용**: SPX500(또는 VOO 근사) 1x, C전략(거치 없이 매일 20만원, 한도 없음), 목표 10억 — 에 대한
  **사전계산된 결과만** 담긴 파일. 원시 가격 데이터는 포함되어 있지 않음.
- **용도**: SPX500 쪽 백테스트 로직 검증용 대조 데이터. 원시 가격 재현은 `sp500_1927_now.csv`를 사용할 것.

## 재현 체크리스트 (클로드코드가 백테스트 코드를 새로 짤 때)
1. `ndx 1971_now.csv` 로드 → 1985-10-01 스플라이스 보정.
2. 일별 수익률 계산 → leverage(1/2/3) 곱해서 synthetic price 생성.
3. 월별 코호트 시작일 추출 (매월 첫 거래일).
4. A/B/C 전략별로 벡터화된 시뮬레이션 실행 → 표준 스키마로 결과 저장.
5. **검증 단계**: NDX 2x + A전략 + 10억 조합 결과를 `mcv_ndx_2x_monthly_10b.json`과 대조해서
   `final_value`, `years_to_target` 등이 일치하는지 확인 (완벽히 일치하지 않을 수 있음 — 스플라이스
   보정 방식에 따라 소폭 차이 가능, 하지만 전체적인 패턴/통계는 일치해야 함).
6. SPX500 백테스트는 `sp500_1927_now.csv`를 동일한 방식으로 로드하여 실행.
7. 검증이 끝나면 `02_findings_accumulation.md` ~ `05_findings_patterns.md`에 적힌 모든 결론이
   재생성된 데이터에서도 재현되는지 교차 확인 후 사이트에 반영.
