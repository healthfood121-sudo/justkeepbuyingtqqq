# 거치금 분할매수 전략 분석

## 배경 질문
"지금(2026년 기준) 4년째 강세장이 진행 중인데, 2.38억을 한번에 거치하는 것보다 여러 방식으로 나눠 넣는 게
낫지 않을까?" — 이 질문에서 출발해, 매일 20만원 적립은 유지하면서 **목돈을 어떻게 나눠 넣을지** 10여 가지
방식을 테스트함.

## 테스트한 분할 방식 (총 16가지, F1~F16으로 명명)
- **드로다운 트리거형 (F1~F10)**: 평소엔 현금으로 대기하다가, 특정 % 하락(-15%, -20%, -30% 등)이 오면
  나눠서 추가 매수. 강제 기한(3~5년)도 함께 테스트.
- **시간 분할형 — 월 단위 (F11~F13)**: 목돈을 3년/4년/5년에 걸쳐 매월 균등하게 나눠 매수.
- **시간 분할형 — 일 단위 (F14~F16)**: 목돈을 1년/2년/3년에 걸쳐 매일 균등하게 나눠 매수.

## 중요한 버그와 교정 (재현 시 반드시 유의)
드로다운 트리거를 계산할 때 "현재가 전고점 대비 몇 % 하락했는가"를 **전체 역사상 최고점(all-time peak)** 기준으로
계산하면 안 됩니다. NDX 3배 합성가격의 전체 역사상 최고점은 **2000-03-27 닷컴버블 피크**이며, 2026-09-25 현재도
그 피크보다 -14.2% 낮은 상태입니다. 따라서 2000년 이후 시작하는 모든 코호트가 "이미 -92% 하락 상태"로 계산되어
드로다운 트리거가 사실상 즉시 발동하는 오류가 발생했습니다.

**교정**: 드로다운은 반드시 **각 코호트 시작일로부터의 로컬 최고점(local peak)** 기준으로 계산해야 합니다.
```python
local_prices = prices[start_i:]  # 해당 코호트 시작 시점부터의 가격만 사용
local_peak = np.maximum.accumulate(local_prices)
drawdown = local_prices / local_peak - 1
```

## 핵심 발견 (검증됨, 독립 재검증으로 수치 일치 확인)
- **3년에 걸친 분할매수는 TQQQ(3배 레버리지)에 대해서만 유의미하게 최악의 케이스(worst-case)를 개선시킨다.**
  - 최장 소요기간이 **12.24년 → 8.82년**으로 단축됨 (가장 늦게 도달하는 코호트 기준).
  - 분할을 "월 단위로 하든 일 단위로 하든" 결과는 거의 같음 — **빈도(frequency)는 중요하지 않고,
    총 분할 기간(duration)이 3년 이상이어야 한다는 점이 핵심**.
- **이 효과는 2배(QLD), 1배(QQQ), SPX500 1x(VOO)에는 일반화되지 않는다.**
  - 이 종목들에서는 분할 시 오히려 평균/최악 케이스가 **약간 더 나빠짐** (지연 비용이 "저점 매수" 효과를 상회).
- **메커니즘 해석**: 3배 레버리지는 하락 시 드로다운이 극단적으로 깊기 때문에(예: 1x가 -50% 빠질 때 3x는
  훨씬 더 깊게 빠짐), "쌀 때 더 산다"는 효과가 유독 3배에서만 충분히 크게 작동함.

## 재검증 이력
사용자가 "진짜 맞냐"고 재확인을 요청하여, 벡터화 백테스트와 **완전히 별도로 작성한 수동 시뮬레이션**으로
최악 케이스 코호트(1999-12-01 시작, 3년 월 분할)를 교차검증함. 결과가 소수점까지 정확히 일치
(years_to_target=7.613963, final_value=1,002,028,268.90, accumulated_investment=620,800,000)하여
버그가 아님을 확인함.

## 웹사이트 구현 제안

  하는지를 바로 알려주는 도구.
- 반드시 "이 효과는 3배 레버리지 특이적이며, 다른 종목에는 적용되지 않는다"는 경고를 함께 노출.
